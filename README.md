# 无碍同行 · AccessCare

一款面向听障、视障及行动不便人群的公益微信小程序，提供 **辅具免费共享** 与 **手语服务预约** 两条业务线。

> 原生微信小程序开发 · 无后端依赖 · 数据全部存本地 Storage · 内置全局无障碍换肤

---

## 一、功能一览

| 模块 | 页面 | 说明 |
|------|------|------|
| 首页 | `home` | 轮播图、搜索入口、四宫格导航、实时数据概览、热门辅具推荐 |
| 辅具库 | `aids` | 横向分类 `scroll-view`、关键词搜索、`switch` 只看有货、`radio` 排序 |

## 二、核心亮点：全局无障碍换肤

在「我的 → 无障碍设置」中切换开关，**全站样式即时生效，无需重启小程序**：

- **大字体模式**：正文与标题整体放大
- **高对比模式**：黑底黄字，弱视人群可读
- **简洁模式**：隐藏次要信息，降低认知负担
- **字号档位**：三档自由调节

实现机制：

```
globalData.a11y  →  wx.setStorageSync('ac_settings')
                 →  getCurrentPages() 广播 refreshA11y()
                 →  根节点 class  →  WXSS 后代选择器覆盖
```

为此项目立了三条工程约定：

1. **禁止内联尺寸样式** —— 内联 style 的优先级高于 class，会让主题覆盖失效
2. **统一使用 rpx** —— 不用 px，保证不同屏幕宽度下自适应
3. **每页根节点挂载无障碍 class** —— 主题才能穿透到整页

## 四、运行方式

1. 克隆本仓库：`git clone <你的仓库地址>`
2. 打开 **微信开发者工具** → 导入项目
3. 目录选择 `accessCare`（注意是这一层，不是仓库根目录）
4. AppID 选择「使用测试号」，或填入自己的 AppID
5. 点击「编译」即可运行

首次启动会自动写入初始库存数据。如需重置，在「我的」页面点击「清除缓存」。

**推荐体验路径**：
首页 → 辅具库（筛选与搜索）→ 辅具详情（图片预览、收藏）→ 申请借用（填写并提交）→
我的记录（审核、归还、展开时间轴）→ 我的（无障碍设置：开启大字体与高对比后返回首页观察变化）

## 五、数据说明

项目不使用任何后端服务，**所有业务数据保存在小程序本地 Storage**：

| 键名 | 内容 |
|------|------|
| `ac_orders` | 借用 / 预约记录（含状态流转与时间轴） |
| `ac_stock` | 各辅具实时可借数量 |
| `ac_favorites` | 收藏的辅具编号 |
| `ac_feedback` | 意见反馈记录 |
| `ac_user` | 用户信息 |
| `ac_settings` | 无障碍设置 |
| `ac_seeded` | 种子数据版本号，防止每次启动覆盖已有数据 |

业务记录遵循五态状态机：`pending → ongoing → done | canceled | overdue`，状态流转时库存自动联动。

在开发者工具「调试器 → Storage」面板可直接查看这些键的实时值。

## 六、自测

数据层逻辑可在不开开发者工具的情况下直接验证：

```bash
node tools/_selftest.js
```

脚本用 Node 模拟 `wx.getStorageSync` / `wx.setStorageSync`，把借用、审核、归还、取消、预约、逾期判定的完整流程跑一遍，共 38 项断言。

## 七、技术约定

- 原生小程序框架，未使用任何 UI 组件库
- 尺寸单位 **100% 使用 rpx**，无 px
- 样式不写内联尺寸，主题 class 才能覆盖
- 图片素材由 `tools/make_icons.py` 用 Python 标准库（`zlib` + `struct`）逐像素生成，不依赖 Pillow，无第三方版权风险
- 代码含完整中文注释
